# F26A — A08-01 SPI controller separation (build only)

Parent `02872a12220a8e2ff52863d16f71d6d720e462c1`, tree `08582b9db063fbad0aaf94a026721cd93e9a99a0`. F25D remains accepted until guarded local commit. No physical ownership, flash, SD operation, RF relay, push or cloud.

The Arduino-ESP32 3.3.12 archived HAL maps FSPI index 0 to SPI2 and HSPI index 1 to SPI3 on ESP32-S3 (both lock configurations). LoRa uses `SPIClass loraSPI(FSPI)`. The old F24Y adapter selected SPI2 in four places. The corrected shared adapter uses one `spi_host_device_t` constant `kSdHost=SPI3_HOST` for bus initialization, host slot, device host and bus free; target and Arduino index compile guards reject unsupported mappings. Arduino indices are not IDF enum values. Preserve pin routing, 1 MHz SD clock, no-format mount, checked unmount/free and sticky fault behavior. Do not mount from the live application.

F26A inherits exactly F25D flags. The legacy logger's HSPI instance is excluded by F25A and the separate probe is disabled. Scoped direct SPI instance/bus operation inventory was reviewed; Arduino global `SPI` also uses FSPI on this target, and no direct global `SPI.begin` was found in scoped shared/universal source. Transitive third-party library behavior, dynamic pin ownership and actual physical arbitration remain unproven. Earlier F24Y/Z profiles share the corrected source but are not recompiled here and are not authorized for physical use. No new features, storage clients, session grants or GPIO/power changes. Inherited scheduled LoRa TX means NOT globally RF silent if incorrectly flashed.

The F24Y historical source contract's three literal SPI2 expressions are updated to require the same checked calls using `kSdHost`; all other assertions remain unchanged. New source contract pins four archived SPI core files, verifies mapping, explicit owner inventory, pins, actual denial path and inherited flags. Windows checks installed core and SDK provenance before/after build; host tests exercise the existing checked VFS and permanent-deny runtime, not real SPI or FAT. A successful target compile/link is not a bench test. Actual exclusive SPI3 owner, card power/identity, latency, concurrent RF, and durability remain A08 blockers.
